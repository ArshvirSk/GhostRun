# GhostRun — Specification: Privacy-Safe Analytics & Crash Reporting (NF-17)

> **Status:** Implemented (Wave 2 · NF-17)  
> **Companions:** `docs/WAVES.md`, `docs/NEW_FEATURES.md §5 (NF-17)`

## 1. Executive Summary

Understanding group drop-off across the deployment funnel (install $\to$ sign-up $\to$ first lobby $\to$ match completed) is essential for game refinement. However, telemetry must never compromise player physical security.

**NF-17 (Privacy-Safe Analytics)** mandates:
1. **Strict Consent C7 Gating**:
   - Off by default. Explicit opt-in toggle in `app/settings.tsx` ("Privacy-Safe Diagnostics").
   - Synced with server consent record (`set_consent('diagnostics', granted)`).
2. **Absolute Privacy Firewall**:
   - Zero coordinates: `lat`, `lng`, `latitude`, `longitude`, `coordinates` are actively stripped by sanitizer.
   - Zero personal identity: `name`, `display_name`, `email`, `body`, `message` are actively rejected.
   - Only anonymous milestone funnel events (`install`, `signup_completed`, `lobby_joined`, `game_started`, `game_completed`, `rematch_started`, `crash_reported`) and aggregate numbers.
