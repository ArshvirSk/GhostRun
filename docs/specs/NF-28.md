## 1. Executive Summary

GhostRun is built for community squads and physical outdoor fitness. In accordance with standing architectural decision **F-D9** ("Skip monetisation until a public launch"), the monetisation framework ships strictly **disabled by default**.

**NF-28 (Hosting Purchase Safeguards)** provides:
1. **Disabled-by-Default Feature Flag**:
   - Gated behind `monetisation_enabled: false`.
   - When disabled, all hosting features (including 150-player Event Mode) are completely free, open, and unrestricted.
2. **Permanent Community Protection**:
   - Standard matches (up to 8 players) are permanently free under all circumstances.
3. **Event Host Pass (Preparation Scope)**:
   - For hypothetical future public large-scale tournaments, an Event Host Pass entitlement model is provided with zero tracking or advertising SDKs.
