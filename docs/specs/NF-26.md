## 1. Executive Summary

Maintaining live operations requires remote feature toggles and emergency mode kill-switches without publishing new app binaries. Administrative operations are secured using an explicit `admin_users` table in Postgres, never embedding service-role keys in clients.

**NF-26 (Admin Console & Remote Config)** provides:
1. **Secure Admin Role & RLS**:
   - `admin_users (user_id, granted_at)`
   - Function `is_admin_user()` guarantees only verified administrators can execute mutations or inspect operational telemetry.
2. **Dynamic Remote Config Flags**:
   - `remote_config_flags (key, value, description, updated_at, updated_by)`
   - Provides global kill-switches (`disabled_modes`, `push_notifications_enabled`, `scheduled_games_enabled`) and minimum client version gating (`min_app_version`).
   - Readable by all client applications; writable only by admins.
3. **Anonymous Health Metrics**:
   - RPC `get_system_health_metrics()` aggregates user totals, active live games, unhandled reports, and active push tokens with zero identifiable coordinates or personal records.
