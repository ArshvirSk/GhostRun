## 1. Executive Summary

Players love sharing post-match accomplishments and route maps to social media (WhatsApp, Instagram Stories, Discord). However, exposing raw GPS coordinates can reveal private home addresses, school locations, or meeting points.

**NF-10 (Shareable Round Card)** guarantees:
1. **Mandatory Privacy Trimming**:
   - Trims the first 150m (start/home) and last 150m (finish/home) of the route (`PRIVACY_TRIM_METERS = 150`).
   - If total route distance is under 350m (`MIN_SHAREABLE_DISTANCE_METERS = 350`), route coordinates are completely suppressed to prevent inferring addresses from short loops.
2. **Consent C3 Gating**:
   - Only the player's *own* route is exported, and only if `share_trail` was approved for that match.
   - If `share_trail` is false, route coordinates are omitted and the scorecard marks "Route: Confidential".
3. **Tactical Scorecard**:
   - Displays mode name, outcome (`VICTORIOUS` / `COMPLETED`), duration, distance (km), top speed (km/h), and date.
   - App watermark and link `https://ghostrun.app`.
   - Explicit user privacy warning displayed before sharing.

## 2. Technical Architecture

### 2.1 Core Utilities (`src/lib/roundCard.ts`)
- `trimTrailPrivacy(path, trimMeters = 150)`: Calculates cumulative path distances, filters points between `[150m, total - 150m]`, returns trimmed path.
- `formatRoundCardShareText(metrics)`: Formats tactical text for the system share sheet.

### 2.2 Client UI
- `src/components/ShareRoundCardModal.tsx`:
  - Tactical preview card styled with Afterimage dark tokens.
  - Privacy indicator chip explaining trimming or confidential status.
  - Share via system sheet button (`Share.share`).
- `app/result/[id].tsx`:
  - Card 6 in the result recap carousel triggers the `ShareRoundCardModal`.
