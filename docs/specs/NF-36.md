## 1. Executive Summary

Allowing players and tournament organizers to share custom rulesets increases tactical variety without jeopardizing physical safety or introducing code execution vulnerabilities.

**NF-36 (Community Rule Packs)** provides:
1. **Strictly Data-Only Schema**:
   - Accepts pure JSON data only.
   - Blocks all executable scripts, bytecode, `eval`, `function`, and prototype pollution vectors (`__proto__`).
2. **Immutable Physical Safety Invariants**:
   - Tag radius: strictly capped between 5m and 30m.
   - Ping interval: strictly bounded between 10s and 120s.
   - Boundary radius: bounded between 100m and 2000m.
   - Vehicle transport and location spoofing can **never** be permitted or disabled.
3. **Structured Community Schema**:
   - Defines metadata (`id`, `name`, `author`, `version`, `description`) and gameplay configuration (`rules`).
