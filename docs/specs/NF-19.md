# GhostRun — Specification: Official Website & Join Gateway (NF-19)

> **Status:** Implemented (Wave 4 · NF-19)

## 1. Executive Summary

A public-facing static web presence serves as the universal gateway for deep-linking players into lobbies, reviewing safety protocols, inspecting privacy terms, and contacting support.

**NF-19 (Official Website & Join Gateway)** provides:
1. **Static Web Gateway (`public/`)**:
   - `public/index.html`: Hero landing, game features overview, download buttons, links to subpages.
   - `public/safety/index.html`: Road awareness, 18+ policy, night curfews, emergency SOS explanation.
   - `public/privacy/index.html`: Ephemeral telemetry rules, 150m privacy start/finish trimming, consent choices C1–C7, account deletion path.
   - `public/support/index.html`: Official support contact (`support@ghostrun.app`) and in-app diagnostics instructions.
   - `public/join/index.html`: Universal link gateway redirecting mobile users into the app (`ghost-run://join?code=...`) with Google Play store fallback.
2. **Platform Verification**:
   - `public/.well-known/assetlinks.json`: Android App Links verification.
   - `public/.well-known/apple-app-site-association`: iOS Universal Links verification.

---

## 2. Technical Architecture

- Static assets hosted under `public/`.
- Zero tracking pixels or advertising cookies.
- Complies with WCAG AA accessibility standards.
