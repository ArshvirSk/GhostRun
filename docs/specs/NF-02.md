## 1. Executive Summary

Friction in joining lobbies is the primary drop-off point for multiplayer games. Reading 4-character codes over voice or typing them manually slows group deployment.

**NF-02 (Invite Links & Share Sheet)** provides:
1. **One-Tap Share Payload**:
   - Formatted tactical message template with mode name, lobby code, direct deep link, and fallback web link.
   - Dispatched via system share sheet (`Share.share`) across messaging platforms (WhatsApp, Messages, Discord, Telegram, etc.).
2. **Deep-Linking & App Links**:
   - Direct app scheme: `ghost-run://join?code=ABCD` (and `ghost-run://join/ABCD`).
   - Universal Web App Links: `https://ghostrun.app/join/ABCD` (and `https://ghostrun.app/join?code=ABCD`).
   - Android Intent Filters configured with `autoVerify: true` in `app.json`.
3. **Web Fallback Landing Page (Minimal NF-19)**:
   - Hosted at `/join/<CODE>` (`public/join/index.html`).
   - Displays tactical mission briefing, room code, Play Store install button, and auto-launches the `ghost-run://` deep link on mobile browsers.
4. **Digital Asset Links Verification File**:
   - `public/.well-known/assetlinks.json` declaring package `com.ghostrun.app` with `delegate_permission/common.handle_all_urls`.
5. **In-App QR Deployment Modal**:
   - High-contrast QR code generated in the lobby for physical in-person scanning without typing.
   - Auto-extracts code when full links or deep links are pasted into `app/join.tsx`.

## 2. Technical Architecture

### 2.1 Core Utilities (`src/lib/invite.ts`)
- `buildInvitePayload(options)`:
  - Formats title, tactical message, custom scheme deep link (`ghost-run://join?code=ABCD`), and web link (`https://ghostrun.app/join/ABCD`).
- `parseInviteUrl(input)`:
  - Extracts 4-character uppercase code from direct codes, custom deep link query/path, or web URLs with query or path segments.
- `generateAssetLinksJson()`:
  - Outputs Android Digital Asset Links array for App Links domain verification.
- `generateFallbackLandingHtml(options)`:
  - Standalone Afterimage/Radar styled responsive HTML for web fallback.

### 2.2 Client Integration
1. **`app/lobby/[id].tsx`**:
   - Top header code wrap includes `SHARE` button (opens native share sheet with tactical payload) and `QR` button (opens modal).
   - `LobbyInviteModal` renders generated QR code, large room code with copy action, and direct link actions.
2. **`app/join.tsx`**:
   - Auto-extracts 4-character code from `params.code` or pasted links using `parseInviteUrl`.
   - Supports direct code entry, paste, deep link, and QR scan.
3. **`app.json`**:
   - Registered `intentFilters` for Android App Links (`https://ghostrun.app/join*`) with `autoVerify: true`.
